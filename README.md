# 🐾 Adopta un Amigo
App web para adoptar animales. Entras, ves quién busca hogar, conoces su historia y con un clic lo adoptas. La adopción se guarda en una base de datos, así que si recargas la página todo sigue ahí.
## Capturas
### Lista de animales
La página principal muestra todos los animales con su foto, nombre, especie y edad. En este ejemplo la tortuga **Calvin** ya está adoptada: su tarjeta aparece en gris y con la etiqueta **Adoptado**.

## Qué puedes hacer
- Ver la lista de animales disponibles.
- Buscar por nombre o por especie.
- Entrar al detalle de cada animal.
- Adoptarlo con un clic; queda marcado y el contador de la barra baja.
- Los adoptados se muestran en gris con su etiqueta.
